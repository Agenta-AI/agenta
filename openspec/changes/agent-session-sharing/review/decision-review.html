1. DECIDED

Can colleagues contribute to a shared chat?

Example
AliceI invited Bob to continue this conversation.
AgentaBob can read the history and send requests if he can use the agent.
In specKeep Owner, Participant, and Viewer. Sharing includes history, future replies, and files.
AlternativeView-only sharing would reduce collaboration and is withdrawn.

Named invitations need one row per user and role. No separate publication step is needed.

2. DECIDED

What stays unchanged for existing users?

Example
Existing userWill I lose my prompts, evaluations, or dashboards?
AgentaYour existing project access and trace permissions remain unchanged.
In specExisting agents become project-visible. Only verified human-owned agent chats migrate to private. Unknown owners remain project-visible.
AlternativeMaking every old session private could hide automated or evaluation work from its team.

Do not infer a human owner from a creator ID alone.

3. DECIDED LIMIT

Who can inspect private chats through traces?

Example
AliceCan a project trace reader inspect captured messages from this private chat?
AgentaYes. This release keeps existing trace access.
BaselineKeep existing trace and analytics permissions. This preserves existing use but leaves the content exception.
Restricted policyAdmin-only traces reduce the audience. Other users also lose the analytics and some cost displays that use trace access. This is an explicit policy choice, not a migration default.
LaterSeparate usage metrics from content access after reviewing a limited metrics interface. No tracing redesign is included now.

The spec does not claim confidentiality from trace readers or introduce an automatic admin-only policy for new projects.

4. DECIDED

How do Slack sessions work without account linking?

Example
Slack userI have no Agenta account. Can I ask the installed agent?
AgentaYes, in an allowed Slack place. The agent uses its configured account.
In specPeople who can use the agent in Agenta can read its Slack history there, including direct messages. External senders do not gain the installer's general authority.
AlternativeLinking every Slack identity adds account setup and is outside this release.

A changed or removed installation must not change which agent owns historical conversation access.

5. PROPOSED DETAIL

Should sharing with the whole project let everyone reply?

Example
AliceLet everyone in Sales read my research, but only Bob continue it.
AgentaProject sharing gives read access. Bob has a separate Participant invitation.
In specProject-wide sharing gives Viewer access. Invite named Participants.
AlternativeOffer project-wide Viewer or Participant. This supports open team rooms but adds a broader sharing choice.

The first option keeps the initial controls small. Named collaboration remains available.

6. PROPOSED DETAIL

What happens to Slack when I make its agent private?

Example
AliceMake this shared support agent private again.
AgentaConfirm its owner and review the affected installations. Its Slack installation will pause.
In specPause external invocation. Keep web-session history under its own sharing. Slack history follows the now-private agent. Sharing the agent again does not automatically restart Slack.
AlternativeKeep the installation running under an explicit external grant. This permits outsiders to keep using a private agent and needs a clearer additional control.

Pausing makes the meaning of private easier to understand. Existing trace content remains under trace permissions.

7. PROPOSED DETAIL

Can an administrator open a private session just because they are an admin?

Example
AdminI manage the project. Can I open Alice's private chat?
AgentaNot through session sharing alone. Existing trace permissions remain the stated exception.
In specDo not add an admin bypass to private agent/session access. Allow recovery of ownerless project-visible agents.
AlternativeAdd a separate investigation policy with explicit authorization and records. This needs a distinct review.

Project administration and content access remain separate decisions.
