# Presentational · Media

Image and avatar helpers that add fallback / preview behaviour around a raw image.

| Component             | What it is                                        |
| --------------------- | ------------------------------------------------- |
| **ImagePreview**      | Click-to-zoom image with a lightbox.              |
| **ImageWithFallback** | `<img>` that swaps to a placeholder on error.     |
| **InitialsAvatar**    | Avatar that derives initials + color from a name. |

**How to read these stories**

- Stories use sample image URLs and a broken URL so the fallback path is exercised.

Open a component's **Docs** tab for its full prop table.
