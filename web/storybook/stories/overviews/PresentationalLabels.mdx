# Presentational · Labels

Inline text labels that format an entity fact — an author, a revision, a path, a date — into
a consistent readout. They compose `@agenta/ui` primitives (icon + text).

| Component                 | What it is                                   |
| ------------------------- | -------------------------------------------- |
| **AuthorLabel**           | Avatar + author name for a change.           |
| **RevisionLabel**         | Variant + `vN` revision readout.             |
| **EntityPathLabel**       | Breadcrumb-style path to an entity.          |
| **EntityNameWithVersion** | Entity name suffixed with its version tag.   |
| **EntityListItemLabel**   | Row label: icon + name + meta for list rows. |
| **EntityIconLabel**       | Type icon + name label.                      |
| **FormattedDate**         | Relative / absolute date with tooltip.       |

**How to read these stories**

- Names / versions / dates are passed as props (no atoms or fetchers), so the stories render
  off static sample data.

Open a component's **Docs** tab for its full prop table.
