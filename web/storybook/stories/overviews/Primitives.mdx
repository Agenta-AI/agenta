# Primitives

Primitives are the base `@agenta/ui` components the rest of the app builds on. Geometry comes
from the shared `controlScale` tokens and colors from semantic theme tokens, so light and
dark both track the app.

They are grouped by role:

- **Forms** — data-entry controls (Button, Input, Select, Checkbox, Radio, Switch, …).
- **Overlays** — floating surfaces (Dialog, Sheet, Tooltip, Dropdown, AlertDialog).
- **Display** — read-only presentation (Badge, Avatar, Alert, Divider, Collapse, Tabs, …).
- **Feedback** — loading / progress (Skeleton, Spinner, Progress).

Open each subfolder's **Overview** for its component table and conventions.
