# Feedback primitives

The loading / progress indicators of `@agenta/ui`. Each story renders the component with its
variants.

| Component    | Notes                                                  |
| ------------ | ------------------------------------------------------ |
| **Skeleton** | line / block / avatar placeholders; shimmer animation. |
| **Spinner**  | indeterminate loader; sizes track control tokens.      |
| **Progress** | line / circle; determinate percentage + status colors. |

**Conventions**

- Geometry comes from the shared `controlScale` tokens, so sizing / radius match the app.
- Colors are semantic theme tokens (`colorPrimary`, `colorFillSecondary`, …) — never raw
  hex — so light and dark themes both track the app.

Open a component's **Docs** tab for its full prop table.
