# Presentational · Layout

Structural scaffolding — page shells, panels, section headers, footers, split panes — that
arrange other content. Their stories render sample children to show the frame.

| Component                  | What it is                                              |
| -------------------------- | ------------------------------------------------------- |
| **Section**                | Titled content section with optional actions.           |
| **PageLayout**             | Page shell with tabbed header + body.                   |
| **SplitPanelLayout**       | Two-pane split with a divider.                          |
| **ModalContentLayout**     | Body/scroll frame for modal contents.                   |
| **PanelFooter**            | Sticky action row at a panel's bottom.                  |
| **PanelHeader**            | Title + actions row at a panel's top.                   |
| **HeightCollapse**         | Animated height expand/collapse wrapper.                |
| **NumberedStep**           | Numbered step row for guided flows.                     |
| **CollapsibleGroupHeader** | Expandable group header for grouped rows.               |
| **ConfigAccordionSection** | Accordion section for config panels.                    |
| **MetadataHeader**         | Key/value metadata strip with tooltips.                 |
| **ScrollSentinel**         | Invisible intersection marker for scroll/infinite-load. |

**How to read these stories**

- Stories fill each frame with placeholder children so the spacing / structure is visible.

Open a component's **Docs** tab for its full prop table.
