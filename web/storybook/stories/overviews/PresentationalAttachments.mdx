# Presentational · Attachments

Components for displaying and uploading chat / prompt attachments (images and documents).
They are `@agenta/ui` composites with no single antd counterpart; the upload variants still
lean on antd `Upload` internally.

| Component                | What it is                                        | antd inside?                                                       |
| ------------------------ | ------------------------------------------------- | ------------------------------------------------------------------ |
| **ImageAttachment**      | Thumbnail tile for an attached image.             | none (pure)                                                        |
| **FileAttachment**       | Chip for an attached document with remove action. | antd `Button`, `Tooltip`                                           |
| **AttachmentGrid**       | Grid of image / file attachment tiles.            | none (pure)                                                        |
| **PromptImageUpload**    | Image picker with progress + preview.             | antd `Upload`, `Button`, `Input`, `Progress`, `Spin`, `Typography` |
| **PromptDocumentUpload** | Document picker with add-by-URL.                  | antd `Upload`, `Button`, `Input`, `Typography`                     |

**How to read these stories**

- The **antd** column names the antd parts still used internally — that doubles as a
  migration to-do — and reads _none (pure)_ for the display-only tiles.
- Stories render off static sample attachments; upload flows are mocked (no real network).

Open a component's **Docs** tab for its full prop table.
