# Presentational · Attachments

Components for displaying and uploading chat / prompt attachments (images and documents).
They are `@agenta/ui` composites: display tiles and upload pickers.

| Component                | What it is                                        |
| ------------------------ | ------------------------------------------------- |
| **ImageAttachment**      | Thumbnail tile for an attached image.             |
| **FileAttachment**       | Chip for an attached document with remove action. |
| **AttachmentGrid**       | Grid of image / file attachment tiles.            |
| **PromptImageUpload**    | Image picker with progress + preview.             |
| **PromptDocumentUpload** | Document picker with add-by-URL.                  |

**How to read these stories**

- Stories render off static sample attachments; upload flows are mocked (no real network).

Open a component's **Docs** tab for its full prop table.
