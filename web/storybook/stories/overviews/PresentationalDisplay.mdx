# Presentational · Display

Small **presentational** components that render an entity or metric. They are composites
built from `@agenta/ui` primitives.

| Component                   | What it is                                                              |
| --------------------------- | ----------------------------------------------------------------------- |
| **EntityCard**              | Catalog-style tile: icon + title + description + tag pills + meta slot. |
| **EntityTypeIcon**          | Icon keyed off an entity/workflow type.                                 |
| **ExecutionMetricsDisplay** | Compact latency / token / cost readout.                                 |

**How to read these stories**

- Each story renders the component alone, with sample data.

Open a component's **Docs** tab for its full prop table.
