# Presentational · Feedback

Loading / empty placeholders shaped for specific surfaces (list rows, tables) plus a
copy-on-click tooltip. They compose the feedback primitives into a ready-made state.

| Component           | What it is                                                          |
| ------------------- | ------------------------------------------------------------------- |
| **LoadingSkeleton** | `variant="paragraph"` (text rows) or `"list"` (avatar + line rows). |
| **TableEmptyState** | Empty-table message + action slot.                                  |
| **CopyTooltip**     | Tooltip that copies its target on click.                            |

_**LoadingSkeleton** merged the former **ListItemSkeleton** (list) + **TableLoadingState** (paragraph) into one component on the `@agenta/ui` Skeleton primitive._

**How to read these stories**

- Stories toggle the loading / empty state via controls so both branches are visible.

Open a component's **Docs** tab for its full prop table.
