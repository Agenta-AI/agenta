# Overlays primitives

The floating / portalled surfaces of `@agenta/ui`. These are **Radix-based, compound**
primitives (`Trigger` + `Content` + parts). The app's `EnhancedModal` / `EnhancedDrawer` are
prop-friendly facades layered over `Dialog` / `Sheet`.

| Component       | Notes                                                                 |
| --------------- | --------------------------------------------------------------------- |
| **Dialog**      | compound (`Dialog.Trigger/Content/Header/Footer`); modal radius 16px. |
| **AlertDialog** | confirm/destructive variant with focused actions.                     |
| **Sheet**       | side panel; `side` + `size` props.                                    |
| **Tooltip**     | hover/focus label; `provider` + `Trigger`/`Content`.                  |
| **Dropdown**    | menu overlay; compound trigger/content/item.                          |

**Conventions**

- Geometry comes from the shared `controlScale` tokens (8px radius on controls, 16px on the
  dialog).
- Colors are semantic theme tokens (`colorBgElevated`, `colorBorder`, …) — never raw hex —
  so light and dark themes both track the app.
- `EnhancedModal` / `EnhancedDrawer` render through these primitives; see the **Enhanced**
  section.

Open a component's **Docs** tab for its full prop table.
