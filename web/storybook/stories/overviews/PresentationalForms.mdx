# Presentational · Forms

Labelled / composite form controls that pair an input with a label, header, or extra
behaviour (inline edit, commit message, slider-with-number, path picker). They compose the
input primitives.

| Component                | What it is                                      |
| ------------------------ | ----------------------------------------------- |
| **LabelInput**           | Input with an attached label.                   |
| **LabeledField**         | Label + control + help/error wrapper.           |
| **FieldHeader**          | Field label row with action / help affordances. |
| **CommitMessageInput**   | Commit-message text field with counter.         |
| **SliderInput**          | Slider bound to a number input + stepper.       |
| **EditableText**         | Click-to-edit inline text field.                |
| **SimpleDropdownSelect** | Lightweight dropdown-backed select.             |
| **PathSelectorDropdown** | Dropdown for selecting a data path.             |

**How to read these stories**

- Values are wired to story controls / local state so the edit and selection states are
  interactive.

Open a component's **Docs** tab for its full prop table.
