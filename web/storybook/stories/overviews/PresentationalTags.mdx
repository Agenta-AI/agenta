# Presentational · Tags

Small labelled pills that render a domain status or attribute (environment, sync state,
draft, source, version, type). They map fixed domain values onto a tag built on the
`@agenta/ui` **Badge** primitive.

| Component            | What it is                                           |
| -------------------- | ---------------------------------------------------- |
| **StatusTag**        | Generic status pill with color per state.            |
| **EnvironmentTag**   | Deployment environment label (dev / staging / prod). |
| **DraftTag**         | "Draft" marker for uncommitted entities.             |
| **SyncStateTag**     | Synced / out-of-sync indicator with tooltip.         |
| **MappingStatusTag** | Column-mapping status for testsets.                  |
| **SourceIndicator**  | Where an entity originated (UI / SDK / …).           |
| **VersionBadge**     | `vN` revision tag.                                   |
| **TypeChip**         | Entity / workflow type chip.                         |

**How to read these stories**

- Each story enumerates the domain values so every color / state variant is visible at once.

Open a component's **Docs** tab for its full prop table.
