# Display primitives

The read-only presentation components of `@agenta/ui`. Each story renders the component with
its variants.

| Component      | Notes                                                         |
| -------------- | ------------------------------------------------------------- |
| **Badge**      | cva `variant` × `size`; the base for the presentational tags. |
| **Avatar**     | image / initials fallback; sizes track control tokens.        |
| **Alert**      | info / success / warning / error, optional icon + action.     |
| **Divider**    | horizontal / vertical, optional label.                        |
| **Collapse**   | accordion; watch `fontHeight` (22px) on header rows.          |
| **Tabs**       | line / card variants; compound `Tabs.List/Trigger/Content`.   |
| **Breadcrumb** | separators + overflow; inline `fontHeight` 22px.              |
| **EmptyState** | icon + title + description + optional action slot.            |

**Conventions**

- Geometry comes from the shared `controlScale` tokens (8px radius, 12px font, 22px inline
  `fontHeight`).
- Colors are semantic theme tokens (`colorText`, `colorBorder`, `colorFill*`, …) — never raw
  hex — so light and dark themes both track the app.

Open a component's **Docs** tab for its full prop table.
