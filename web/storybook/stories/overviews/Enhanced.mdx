# Enhanced

Prop-friendly facades over the `@agenta/ui` primitives. Call-sites pass a familiar prop shape
(`open`, `onCancel`, `placement`, `type`, `loading`, …), and the render goes through the
primitive underneath.

| Component          | Facade over | Notes                                               |
| ------------------ | ----------- | --------------------------------------------------- |
| **EnhancedModal**  | `Dialog`    | `open` / `onCancel` props on `Dialog`; radius 16px. |
| **EnhancedDrawer** | `Sheet`     | `placement` and `width` props mapped to `Sheet`.    |
| **EnhancedButton** | `Button`    | `type`, `loading`, `icon` props mapped to `Button`. |

**Conventions**

- The facade keeps one prop shape for call-sites; only the underlying render is `@agenta/ui`.
- Geometry and color flow from the shared `controlScale` tokens and semantic theme tokens, so
  the facades match the primitives in light and dark.

Open a component's **Docs** tab for its full prop table.
