# Forms primitives

The data-entry controls of `@agenta/ui`. Each story renders the component with its variants
and states.

| Component     | Notes                                               |
| ------------- | --------------------------------------------------- |
| **Button**    | cva `variant` × `size`; `LoadingButton` for async.  |
| **Input**     | affix / clear / password / textarea variants.       |
| **Checkbox**  | incl. indeterminate.                                |
| **Radio**     | single + group.                                     |
| **Switch**    |                                                     |
| **Select**    | single/multi; shows a check on the selected option. |
| **Combobox**  | searchable, grouped options.                        |
| **Segmented** |                                                     |
| **Field**     | label + control + help/error composite.             |

**Conventions**

- Geometry comes from the shared `controlScale` tokens (28px control height, 8px radius,
  12px font).
- Colors are semantic theme tokens (`colorText`, `colorBorder`, …) — never raw hex — so light
  and dark themes both track the app.

Open any component's **Docs** tab for its full prop table (types, defaults, required).
