# Add independent credit funding

## Why

Lifetime users must purchase credits without a subscription. Subscription allowances, promotional grants and existing platform entitlements must remain independent.

## What Changes

- Add one-time top-ups independently of subscription checkout.
- Keep credit origin for accounting without requiring purchase-only action restrictions.
- Keep actual lifetime sales-channel integration and final refund/expiry terms explicit decisions.

## Capabilities

### New Capabilities

- `independent-credit-funding`: One-time top-ups and configurable recurring grants without coupling lifetime access to subscriptions.

### Modified Capabilities

None. This standalone package does not claim these capabilities are already published on main.

## Impact

Documentation and proposed behavior only. No implementation, merge, deployment, or commercial pricing approval. See the package README for source revisions and status.
