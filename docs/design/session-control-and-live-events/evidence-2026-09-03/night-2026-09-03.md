## Two defects found live and fixed the same night

- Approval-Stop resume. After a Stop cancelled a parked approval, the runner kept the gate and the
  next message took the approval-resume path, which continued the old prompt; the new text never
  reached the model. This failed 5 of 5 on local and Daytona before the fix. Round two did not
  catch it because its lane asserted recall on a third turn. Fixed on PR #6501 (runner commits
  `2b74e17292`, `83ee1def4a`, `dad60daca1`) and re-proven on Pi local and Daytona.
- Codex reap under concurrency. On the local provider all sandboxes share one process table, so
  the reap disabled itself when more than one `codex app-server` was visible and the stopped
  Codex shell child survived. Fixed on PR #6496 (`cce2b21bc3`) by scoping the reap to the
  sandbox's own daemon port. Daytona was never affected.
