## LinkedIn

Agenta v0.112.0 organizes agent work around sessions.

You can keep several pieces of work moving with the same agent, switch between them quickly, and keep each conversation and its files together. Slash commands let you change the model, runtime, or permissions and reference skills and tools from the composer.

Automation Runs give scheduled and event-triggered work a complete history. Open a run to see what happened, provide supported human input, and use the result to improve the automation for next time.

## Twitter/X

Agenta v0.112.0 adds an Agent Workspace built around sessions, slash commands for in-chat control, and Automation Runs with history and human input.

Keep several tasks moving, inspect how each run unfolded, and improve what happens next time.

## Community Slack

Agenta v0.112.0 is available.

The Agent Workspace now helps you manage several sessions with the same agent. Slash commands bring model, runtime, permission, skill, and tool controls into the conversation. Automation Runs let you inspect scheduled and event-triggered work, provide human input, and improve future runs.
