The Templates page is now the **Agent Marketplace**. It helps you find an agent that already does the job, and see it work before you pick it.

## Find a template

At the top, a featured card cycles through templates that have an example run. Below it, filter by category or by the apps a template connects to, such as Gmail or Linear, or search by name. Press **/** to jump to search.

Click a card to preview the template: its example run, the apps it connects, how it works and the tools it uses.

## The template page

Open the full page for the whole picture: the example run and the agent's instructions, how it works, its tools, and the steps to set it up. The side card shows the model it runs on and who made it. Click **Use this template** to create your agent.

Read more about templates in [Start from a template, or share your agent as one](/changelog/agent-templates-and-marketplace).
