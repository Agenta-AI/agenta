<Summary>

You can now share agent chat session with your teams. Copy a session link and a teammate with access can open (and work with you) that exact session.

</Summary>

{/* truncate */}

When you ask a teammate to review an agent's work, a link to the agent is not enough. It may have dozens of conversations. A session link takes them to the one you want them to read.

## Copy the session link

Open the menu on a session and choose Copy share link. You can use the menu from the session list or the open conversation. Send the link to a teammate who already has access to the project.

They can read the instructions and replies in the original conversation instead of piecing together copied excerpts.

## Return to the same conversation

In the classic playground, the address now follows the session you have open. Reloading or opening that link in a new tab returns to the linked conversation rather than whichever session happened to be open last.

The new app also has Copy share link in its session menus. Sharing a link does not change project permissions, create a public page, or invite a new member.
