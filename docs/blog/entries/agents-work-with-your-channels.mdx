<Summary>

Agents connected to Slack or Telegram can now work with those channels from any run, not just reply to a message. An automation can post its weekly report to #marketing. An agent in chat can catch up on what your team said in #support.

Agents can also share the link to their current chat from anywhere, so every post can point back to the full conversation.

</Summary>

{/* truncate */}

## Post, read and search

When an agent is connected to a Slack workspace or a Telegram bot, it gets four tools:

- **List destinations**: the channels and groups it can reach.
- **Send a message**: post now, or reply in a Slack thread.
- **Read messages**: catch up on a channel's recent messages or one thread.
- **Search messages**: find what was said earlier in the channels it can read.

These work from a chat in Agenta, from a channel conversation, and from automations. For example, schedule an agent to post the release summary in #releases every Friday.

## Link back to the chat

Agents can now get the link to their current chat and rename it in every run, including Slack, Telegram, WhatsApp, the API and automations. When an automation posts a result, it can include the link so you can open the full context.

You choose which Agenta tools an agent gets in **Advanced → Agenta tools**. New agents start with the chat link and rename tools allowed.
