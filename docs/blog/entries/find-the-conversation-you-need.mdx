<Summary>

When you run many agents, finding the right conversation matters. The sidebar now groups sessions by agent, lets you filter, pin and reorder them, and shows which ones are running or waiting for you.

Start a new session from any agent with **+**, and right-click a session for its actions.

</Summary>

{/* truncate */}

## Group, filter and pin

The sidebar groups sessions under their agent. Filter by status, pin the ones you come back to, and drag agents and sessions into the order you like. Sessions that are running or waiting for your answer are marked.

## Act faster

Click **+** on any agent heading to start a new session with that agent. Right-click a session to rename, pin, archive or delete it.

Agent headings stay at the top while you scroll, and the list opens at the session you have open.
