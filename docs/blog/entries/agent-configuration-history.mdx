## What you can do

Edits save automatically as revisions. Review the diff, see what changed, and restore an earlier configuration when needed.

## How it works

Edit the agent normally. Agenta coalesces nearby changes into a revision after a short pause and waits for an active run before saving. Open revision history to inspect a diff or restore an earlier revision.

## Good to know

Auto-save waits for an active run to finish. Confirm the exact restore behavior before calling it a destructive rollback.
