A list of version numbers tells you little when an agent starts behaving differently. You need to see what changed before deciding whether to keep it.

Version history shows the configuration behind each version and the differences from the one you are viewing.

## Review a previous configuration

Click the version chip beside the agent, such as v12, to open its history. Versions appear newest first with their change messages.

Select an older version to see what restoring it would change. The comparison uses names from the configuration, including the names of tools, rather than internal storage fields.

## Restore without erasing history

Choose the version you want to return to, review the differences, then confirm the restore. Agenta saves that configuration as a new version at the top of the history. It does not delete the versions in between.

This restores the agent's configuration, not files it edited or actions it took in connected apps.

## Saving in the new app

In the new app on desktop and mobile, changes to the latest configuration save automatically after a short pause. Saving waits while a run is active or waiting for approval. Check the save status before you leave: a failed save or an edit to an older version may need the Save button.

The classic app keeps its separate commit flow. Version history is available in both apps.
