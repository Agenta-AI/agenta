Each saved change to your agent configuration has a version. You can now open the history, see what changed, and revert to an earlier configuration.

## See what changed

Click the version number next to the agent's name. You'll see the versions, newest first, with a commit message for each one.

Select a version to compare it with the configuration you're viewing. This shows changes to your instructions, tools, and other settings.

## Revert to an earlier version

Select the version you want, review the changes, and confirm the restore. Agenta saves it as a new version, so you keep the history in between.

This changes the agent's configuration. It doesn't undo files the agent edited or actions it took in connected apps.

Version history is available in both the classic and new apps.
