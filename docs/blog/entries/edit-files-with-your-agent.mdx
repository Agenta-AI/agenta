## Edit files where the agent works

Open **Files** in a session and click a Markdown or text file. It opens as an editable document. Code, JSON and HTML files open in a code editor. Very large files open read-only. Your changes save automatically, and the agent sees them the next time it reads the file.

Ask the agent to draft something, edit it yourself, then ask it to continue from your version. You never copy text between tools.

## Organize and link

Right-click in the Files pane to create a file or folder, or upload. Paste a screenshot straight from your clipboard. Links between files open the right file inside Agenta.

The Files pane works on desktop and on your phone.
