<Summary>

We've made big improvements to the way chat sesesions work:

1. You can now queue messages to your agent. These are saved so that they run even if you close the tab. 
2. You can open the same chat session in multiple tabs (or in the browser and chat)
3. You can stop and steer the agent mid-conversation

</Summary>

{/* truncate */}

You do not have to wait for an agent to finish before planning the next step. Add a follow-up message during a run and leave it in the queue.

For example, while an agent drafts a report, queue a request to shorten the introduction. If you change your mind about the wording, edit that queued request instead of deleting it and starting over.

## Correct a queued message

Choose Edit on a message that has not started. Change the text and save it. The message keeps its position and its existing attachments.

Once a message has started, or has been selected for Send Now, it can no longer be edited in the queue. A failed save keeps your draft available so you can retry.

## Work in another session

Switch to another conversation while the agent continues its current work. Return to the session to follow progress or respond if it needs approval. A queued instruction does not answer an approval request for you.

If you need to stop the current run, use Stop. You can continue the conversation afterward. Stopping does not undo tool calls that have already completed, such as a file edit or an email that was sent.
