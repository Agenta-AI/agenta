We've improved how agent chat sessions work. You can queue the next task while your agent is working, open the same conversation in another tab, and change direction during a run.

## Queue the next task

Send a follow-up message while the agent is busy. It waits in the queue until the agent can run it. Queued messages are saved, so closing the tab doesn't remove them. If the agent needs approval or input, it still waits for your response.

You can edit a queued message before it starts. Click Edit, change the text, and save. The message keeps its place and attachments.

## Open the same chat in another tab

You can open the same session in multiple tabs and follow the conversation from either one. You don't need to start a separate chat to return to the task.

## Stop or steer a run

Use Stop to end the current run. You can then send new instructions in the same conversation. Where the runtime supports steering, you can send input to the active run without waiting for it to finish.

Stopping doesn't undo completed actions, such as a file edit or a sent email. See the [sessions and turns reference](/reference/agents/sessions-and-turns) for queue, stop, and steering behavior.
