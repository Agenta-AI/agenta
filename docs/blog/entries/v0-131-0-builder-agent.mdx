## What the builder agent is

The builder agent is an agent that builds your other agents. You tell it what you want in plain words. It then creates the agent and writes its instructions, tools and skills for you.

## Where to find it

- **To start a new agent**, open **Builder** in the sidebar and describe the agent you want.
- **To change an agent you already have**, open the agent and call the builder from the panel next to it. The builder then works on that agent.

## What it can do

- Build a new agent from your description.
- Run the agent to see how it behaves.
- Find what went wrong in a run.
- Improve the agent's instructions, tools and skills.

We will keep making the builder better.
