You can now use your ChatGPT subscription to run agents in Agenta. Connect your account from the model selector, then choose it for your agent.

## Connect your subscription

1. Click the model selector, then Configure models.
2. Choose ChatGPT subscription and start the connection.
3. Copy the device code and follow the link to sign in to ChatGPT.
4. Approve the connection, then return to Agenta.

Once the connection shows Connected, select ChatGPT · Subscription in your agent's model picker and choose a model.

## Use it with your agents

You can use the same connection for more than one agent. This connection uses the Pi runtime and works with local and Daytona runs. It doesn't support the Codex runtime.

Your ChatGPT subscription's eligibility and usage limits still apply. If the connection shows Sign in needed, open it and sign in again.
