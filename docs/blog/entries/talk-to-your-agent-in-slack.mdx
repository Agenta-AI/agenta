You can now talk to your agent in Slack. Add it to your workspace from the agent's Publish button, then mention it in any channel or thread. It answers in the thread and keeps the conversation's context.

You can see where each request stands: the agent adds 👀 when it picks up your message and ✅ when it's done.

## Connect Slack

Open your agent and click **Publish**, then choose Slack. Use the Agenta Slack app with **Add to Slack**, or connect your own Slack app with the manifest we provide. **Add to Slack** appears only when the deployment has the Agenta Slack app configured. On a self-hosted deployment without it, connect your own app.

Each connection answers as one agent. You can see every connection in your project in **Settings → Channels**, and change which agent a bot answers as.

## Work with the agent in a thread

Mention the agent in a channel, a thread, or a direct message. It replies in the thread and remembers what was said there.

In threads and group conversations, the agent only answers when you address it. Messages between teammates don't start a new run.

When the agent needs approval for a tool, it asks in the thread and you answer with a click.

## See the status at a glance

The agent reacts to your message with 👀 when it starts and replaces it with ✅ when it has finished and posted every part of its answer. If a run fails or is cancelled, the 👀 is removed.
