<Summary>

A workspace full of identical robot icons is hard to scan. Give each agent its own icon and color, and use that same visual cue to find it in navigation, open its chat, or select it for an automation.

</Summary>

{/* truncate */}

When you have an agent for research and another for writing, their names should not be the only way to tell them apart. You can now give each one a distinct icon and color.

## Choose a mark for each agent

Open an agent and click the icon beside its name. Pick an icon and a color. The choice applies immediately, without a separate save step.

Use Reset to return to the default appearance. Changing one agent's appearance leaves the others alone.

## Recognize it across the workspace

The same icon appears in the sidebar, agent cards, chat messages, and the agent picker for automations. For example, you could give a research agent a magnifying glass and a writing agent a pencil.

This works in both the classic app and the new app, including on mobile. Your choices are saved in the current browser; they do not sync to another browser or device.
