You can give each agent its own icon and color. If you have several agents in your workspace, this makes them easier to tell apart.

## Change an agent's icon

Click the icon next to the agent's name, then choose an icon and a color. The change applies immediately.

You'll see the same icon in the sidebar, agent cards, chat messages, and automation picker. Click Reset if you want to go back to the default.

This works in the classic and new apps, on desktop and mobile. The choice is saved in your current browser, so you'll need to set it again in another browser or device.
