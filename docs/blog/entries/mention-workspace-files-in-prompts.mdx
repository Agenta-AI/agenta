When you want your agent to work on a file, you shouldn't need to find its path and paste it into chat. You can now type @, search for the file, and select it.

## Select a file

Open an existing session in the new app and type @ in the chat box. You'll see recent files and the session's folders. Keep typing to search by filename.

Select the file, then write what you want the agent to do. For example, choose report.md and add: "Shorten the introduction."

The file path becomes part of your message. You're pointing to the existing file, not uploading another copy.

## Find a file inside a folder

Click a folder's chevron or press Tab to open it. Press Escape to go back.

File mentions work in the new app on desktop and mobile. Open a session first; the file picker isn't available in the home task box.
