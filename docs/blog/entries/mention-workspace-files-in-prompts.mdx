## What you can do

Type @ in the composer, choose a workspace file, and place its reference directly in the instruction you send to the agent.

## How it works

Type @ in the composer, search for a workspace file, select it, and finish the instruction.

## Good to know

The agent still needs access to the referenced workspace path.
