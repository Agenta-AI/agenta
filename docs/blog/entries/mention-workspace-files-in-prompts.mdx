After an agent writes a report, your next request often concerns that same file. You can now point to it from the message box instead of describing where it is or uploading it again.

## Pick a file from the message box

In an existing session in the new app, type @ at the start of a word. The file picker shows recent files and the session's drive. Continue typing part of a filename to search.

Select a file to insert its path into your message, then explain what you want the agent to do. For example: select report.md and ask, "Shorten the introduction and keep the recommendations."

## Browse folders

Use Tab or a folder's chevron to enter it. Escape steps back a level, then closes the picker. You can reference a folder too, although folder references remain text rather than clickable file chips.

File mentions work in the new app on desktop and mobile. They use files already available to the session; they do not upload a copy or grant access to a new location. The picker needs an existing session with a drive, so it is not part of the home task box before a session exists.
