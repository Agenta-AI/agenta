<Summary>

Skills are now shared across your project. Write a skill once, publish it, and install it in any agent.

An agent can pin a skill to one version. When the skill changes, the agent shows that an update is available, and you decide when to apply it.

</Summary>

{/* truncate */}

## Publish and install

Open **Skills** to see every skill in your project. Create one, or import it from a repository, and publish it. Then add it to any agent from the agent's Skills section.

## Update on your terms

Skills keep their versions. An agent can pin a skill to a version or follow its latest version. When a new version is published, a pinned skill shows **Update available**. To update it, add it again pinned to the new version, or switch its reference to Latest. A pinned skill never changes until you update it.

For a skill you imported from a repository, use **Check for updates** in the skill's menu to fetch a newer version.

See [Manage skills](/guides/manage-skills).
