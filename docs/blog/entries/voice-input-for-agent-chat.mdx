You can now talk to your agent instead of typing. Hit the microphone button and Agenta turns your voice into text in the chat box.

## Start talking

Click the microphone and allow microphone access if your browser asks. Speak your instructions, then click again to stop.

You can edit the text before sending it. You can also start with a typed message and dictate the rest.

## Use the keyboard shortcut

Hold Ctrl+Option on Mac or Ctrl+left Alt on Windows and Linux to talk. Release the keys to stop recording. The message stays in the chat box until you send it.

Voice input works in the classic and new apps where the browser supports speech recognition. Firefox isn't supported. Your agent receives the text, not an audio recording.
