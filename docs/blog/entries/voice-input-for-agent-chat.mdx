Some instructions are easier to say than type. A task might need a few minutes of context, or you may want to talk through feedback while looking at the agent's work.

Dictation puts your words into the message box. You still decide what to send.

## Speak, check, send

Click the microphone button, allow microphone access if your browser asks, and start speaking. Click it again to stop. Your transcript stays in the message box, where you can edit it before sending.

You can also dictate after text you have already typed. For example, type a document title, then speak the changes you want the agent to make.

## Hold to talk

On macOS, hold Ctrl+Option to dictate. On Windows and Linux, hold Ctrl+left Alt. Release the keys to stop. Releasing does not send the message.

Only the session on screen responds to the shortcut. Sending the message also stops the microphone.

Dictation is available in the classic and new apps where the browser supports speech recognition. Firefox is not supported. This transcribes speech to text; it does not send an audio recording to the agent.
