## What you can do

Dictate directly into the composer, or use hold-to-talk on supported desktop browsers, then review the transcript before sending.

## How it works

Use the microphone in the composer to dictate. On supported desktop browsers, hold the configured talk shortcut, speak, and release it to finish.

## Good to know

Browser speech support varies; Firefox was excluded in the implementation evidence.
