<Summary>

Select any part of an agent's reply, or a few lines in a file, and reply to just that part. The agent sees the exact text you mean, so you don't have to describe "the second bullet about pricing".

You can also collect quotes from several replies and files and send them in one message.

You no longer have to reply to a whole answer. Point at the sentence, table row or lines you mean, and the agent gets exactly that.

## Reply to a selection

Select text in an agent's reply, or in a file in the Files pane. A small **Copy · Reply** button appears over it. Click **Reply**, write your note and press **Enter** to send it.

A quote from a file includes the file path and the line numbers, so the agent can open the file at the right place.

## Send several quotes at once

Press **⌘/Ctrl+Enter** instead of Enter to add the quote to the message box. Collect quotes from different replies and files, then send them together in one message.

**Copy** copies the selected text.
