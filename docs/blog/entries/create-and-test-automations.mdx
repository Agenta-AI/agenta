<Summary>

Automations are easier to trust now. Create one on a schedule or an event, run a test right away, and follow every run in its own session.

When a run needs your input, you continue it in that session like any other chat.

</Summary>

{/* truncate */}

## Create an automation

Open the agent's **Automations** and add one. Choose a schedule, such as every Monday at 9, or an event from a connected app, such as a new GitHub issue. Write the task the agent should do.

## Test it before you wait for it

Click **Run now** to run it in a new session. You see the run as it happens, so you can fix the task before the first real run.

## Follow every run

Each run opens as its own session. Open the run history to see what happened, and reply in the session if the agent asked for something.

See [Create an automation](/guides/create-an-automation).
