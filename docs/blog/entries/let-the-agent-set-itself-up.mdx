<Summary>

Setting up an agent is now mostly a conversation. The **+** on Integrations, Skills and Automations has a **Create with AI** option that starts the request in chat, so the agent does the setup for you.

Agents created from a template also ask for the accounts they need before their first task, instead of failing halfway through it.

</Summary>

{/* truncate */}

## Create with AI

In the agent configuration, click **+** next to Integrations, Skills or Automations and choose **Create with AI**. The chat box fills in a starter like "I want an automation that ", you finish the sentence and send. The agent sets it up and asks if anything is missing.

You can still add things by hand from the same menu.

## Connect accounts before the first task

When you create an agent from a template, setup now lists the accounts it needs, such as Gmail or Linear, and asks you to connect them first. The first message waits until you are ready.
