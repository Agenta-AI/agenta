## One image for every install

Open source and Enterprise installs now run the same API, services and runner images. A [license key](/self-host/license-keys) decides the plan of the instance. You do not change your compose files, Helm values or env files. Pull the new images and restart.

Take a dump of your core and tracing databases first. On an open source database, the first start adds tables and rows, and you cannot undo this in place. The [upgrade guide](/self-host/upgrading#upgrading-to-0131-1) explains what the first start does.

If your install is older than v0.104.0, upgrade to the latest 0.129.x release first. Then upgrade to 0.131.1.

## Plans and limits

| Plan | Key | Projects per organization | Organizations per instance |
|---|---|---|---|
| Community | No key | 1 | 1 |
| Registered | The free registration key | No limit | 1 |
| Enterprise | A paid key | No limit | No limit |

The limits stop only a new project or a new organization. Projects and organizations that exist before the upgrade stay.

An Enterprise instance that ran without a key moves to the Community plan. Add a key to turn the enterprise features back on. See [License keys](/self-host/license-keys#upgrade-an-existing-enterprise-instance).

## Get a free key

The first time the instance admin opens the app after the upgrade, the app offers to register the instance for a free key. You can also register later from **Settings > License**. See [Get a free registration key](/self-host/license-keys#get-a-free-registration-key).

## Telemetry

Self-hosted telemetry is now anonymous, and you can turn it off. An instance sends a small amount of usage data to Agenta. It never sends your prompts, traces, test sets or model outputs, and never sends emails or names from the instance.

To turn it off:

- Docker Compose: add `AGENTA_TELEMETRY_ENABLED=false` to your `.env` file.
- Helm: set `telemetry.enabled: false` in your values file.

The [Telemetry](/self-host/telemetry) page lists what is sent.

## Update notices

The app now tells you when a newer release or a security fix is out. See [Update notices](/self-host/update-notices).

## Helm

The migration job can now run for up to one hour (`alembic.activeDeadlineSeconds: 3600`). Set the Helm `--timeout` above this value. An Enterprise Helm install now pulls public images and needs no pull secret.
