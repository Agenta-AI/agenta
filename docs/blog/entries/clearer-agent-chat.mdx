<Summary>

Chatting with an agent is easier to follow. Each turn now folds its thinking, tool calls and generated files into one activity timeline, so the answer stays readable.

Answering the agent is faster too. Pick an option and a single-choice question is sent right away. If the agent is waiting on a question, you can just type a message instead.

</Summary>

{/* truncate */}

## One timeline per turn

While the agent works, its thoughts, tool calls and the files it creates appear in one activity timeline above the answer. Expand it when you want the details, and leave it closed when you just want the result. The timer shows how long the run has been going, even after you come back to it.

## Answer in one click

When the agent asks a question with a single choice, clicking an option sends it. No extra Send.

## Or just type

If the agent is waiting for an answer or a connection and you'd rather say something else, type your message. The card closes and the agent reads your message next.
