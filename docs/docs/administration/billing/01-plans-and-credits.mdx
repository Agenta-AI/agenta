This page is for Agenta Cloud. Self-hosted deployments have no plans, credits, or usage limits.

## Credits

Credits pay for two things:

- **Agenta's included models.** You can use them without an API key.
- **Runtime.** The time your agents run.

When an agent uses your own API key or your ChatGPT subscription, the model costs no credits. Its runtime still uses credits. To connect a key or a subscription, see [Connect a provider](/guides/choose-a-harness-and-model#connect-a-provider).

## Tasks

A task is one agent turn: it starts when you send a message and ends when the agent finishes answering. A chat holds many tasks, one for each message you send.

The concurrent tasks limit is the number of tasks your organization can run at the same time. The longest task limit is the longest a single task can run: 30 minutes on Hobby, 4 hours on Starter, and 11 hours on Business. The limit applies to each task, not to the whole chat.

## What a task costs

A typical task uses about 26 credits. The cost depends on the model, how much text the agent reads and writes, and how long it runs. These examples use Gemini 3.7 Flash.

| Task | Credits |
|---|---|
| A short summary of a page or an email thread | About 3 |
| A research report (the agent reads about 35,000 tokens, writes about 28,500, and runs about 3 minutes) | About 26 |
| The same research report with your own API key or ChatGPT subscription | About 3 |
| A scheduled daily summary, every day for a month | About 90 |
| One hour of runtime, before model costs | About 50 |

On Starter, 2,900 monthly credits cover about 110 research reports. The 75 daily credits cover about 3 a day.

| Gemini 3.7 Flash | About 130 | About 13 | About 660 |

### Runtime

About 50 credits an hour, on every plan. This price is for the standard agent size, 2 vCPUs and 4 GiB of memory. Runtime is counted by the second.

## When credits arrive and expire

| Credits | Who gets them | When they arrive | When they expire |
|---|---|---|---|
| Signup bonus: 500 | The organization created when you sign up | At signup | After 12 months |
| Daily credits: 75 | Every plan | On each day you use Agenta, on up to 10 days a month | At midnight UTC. They do not roll over. |
| Monthly credits: 2,900 or 32,000 | Starter and Business | At the start of each billing period | At the end of the billing period |
| Purchased credits | Starter and Business | When you buy them | After 12 months |

Daily credits are spent first, then monthly credits, then signup credits, then purchased credits.

Hobby cannot buy credits. To get more credits on Hobby, upgrade to Starter.

## What happens at a limit

The limits on concurrent tasks and task length apply to agents that run on Agenta.

| Limit | What happens | What to do |
|---|---|---|
| Out of credits | New tasks do not start, and you are not charged for them. Tasks that are already running finish. This includes agents that use your own API key, because runtime uses credits. | Wait for the next day's daily credits (on up to 10 days a month), buy more credits on Starter and Business, or upgrade. |
| Concurrent tasks | The new task does not start, and you are not charged for it. The tasks that are running continue. | Send the task again when one finishes, or upgrade. |
| Longest task | The task stops. Saved work is kept, and you pay only for the time used. | Send a message to continue, or upgrade. |
| Projects on Hobby | You cannot create another project. Projects you already have keep working. | Upgrade to Starter for unlimited projects. |

When a task meets the credit limit or a task limit, the chat shows an error code. See [Agent run errors](/misc/errors#agent-run-errors).

To change your plan, open **Settings**, then **Usage & Billing**.
