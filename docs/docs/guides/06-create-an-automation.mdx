An automation runs an agent for you, without anyone typing in the chat. You decide when it runs and what it should do. Agenta does the rest.

Two things can start an automation:

- **A schedule.** For example, every weekday at 9:00.
- **An event in an app you have connected.** For example, when a new issue is opened in GitHub.

To learn more about how automations work, see [Automations](/concepts/automations).

## Get the agent ready

Open the agent and tell it in the chat what the job is: what to do and where to get the information. The agent sets itself up from that. An automation runs without anyone in the chat, so this is all it will have to go on.

## Create the automation

Go to `Sidebar > Automations` and click `New automation`.

### 1. Give it a name

Type a name, or leave it empty. If you leave it empty, Agenta names it after the schedule and the agent, for example `Weekdays at 09:00 UTC — Support digest`.

### 2. Pick the agent

Under `Agent`, choose the agent you prepared above.

### 3. Choose when it runs

Click `Runs when`. You will see two options at the top:

- `On a schedule`: the agent runs at the times you pick.
- `When something happens`: the agent runs when a certain event happens in an app you have connected.

#### If you chose "On a schedule"

A new automation is set to run every weekday at 9:00 UTC. To change that, pick how often it should run under `Cadence`:

- `Hourly`: every few hours.
- `Daily`: once or more every day.
- `Weekly`: on the days of the week you pick.
- `Monthly`: on the days of the month you pick.
- `Cron`: for people who know cron expressions.

:::note
All times are in UTC (the world's reference time), not your local time. In summer, 9:00 UTC is 11:00 in Berlin and 5:00 in New York.
:::

#### If you chose "When something happens"

The list on the left shows the apps you have connected. An automation can only watch an app that is on this list.

If your app is not there yet, click `Connect another app…`. Search for the app, click it, and click `Connect`. Once it is connected, open `Runs when` again and the app is on the list.

Now click the app, then click the event you want to watch (for example, "issue opened"). Some events ask for a few details first, such as which repository to watch. Fill them in and click `Done`.

### 4. Write the message

Under `Instruction`, write the message the agent receives each time it runs, the same way you would type it in the chat. Say what to do and where to put the result. For example:

> Summarize support tickets from the previous day and post the digest to #ops.

### 5. Create it

Click `Create automation`.

## Check the automation's history

Every run is saved, together with the full conversation the agent had. Open the automation and click the `Run history` card.
