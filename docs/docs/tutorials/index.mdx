Each tutorial builds one real agent from scratch. You build it by chatting with the agent: you describe the job, connect the apps it needs, save what works as a skill, and then automate it.

Every tutorial has a video and a written version of the same steps. Watch the video for the full picture, and use the written version to follow along.

| Tutorial | What you build | Video |
| --- | --- | --- |
| [Build your first AI coworker](/tutorials/build-your-first-ai-coworker) | A sales copilot that researches prospects and prepares you for every sales call. | 10 min |
| [Track your competitors while you sleep](/tutorials/track-your-competitors) | An agent that researches your competitors every Monday and emails you a digest. | 7 min |
| [Build an inbound outreach agent](/tutorials/build-an-inbound-outreach-agent) | An agent that finds newly activated users, researches them, and drafts personal emails for you to approve in Slack. | 17 min |

If you are new to Agenta, start with [Build your first AI coworker](/tutorials/build-your-first-ai-coworker). It introduces the parts of an agent that the other tutorials use.

## The pattern behind every tutorial

All three tutorials follow the same steps:

1. **Connect the tools.** Add the integrations the agent needs, such as Gmail, Slack, or a web search tool.
2. **Solve the task once, together.** Ask the agent to do the job in a chat, look at the result, and give feedback until it is right.
3. **Save it as a skill.** Ask the agent to turn what worked into a skill, so it does the job the same way next time.
4. **Automate it.** Ask the agent to run the job on a schedule or when something happens in a connected app.
5. **Keep improving.** When a run is not quite right, tell the agent. It updates its own instructions and skills.
