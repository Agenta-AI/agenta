# Prospect research

1. Read the confirmed target criteria before evaluating a company.
2. Prefer the company's official website for product and contact facts.
3. Record facts with source URLs. Separate facts from uncertain interpretations.
4. Explain which criteria match, which do not, and which remain unknown.
5. Return a short assessment. Do not invent personal contact details or send outreach.
