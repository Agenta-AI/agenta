Background (from the session that started this one):
Today, on the first turn of a new session, the model usually calls `rename_session` (and `rename_agent` for placeholder-named agents) before it writes any text. A tool call ends the model call, so the reply waits for a second model call: first text at 6.6 to 9.3 s on staging (built-in Gemini, in-process Pi) versus 3.0 to 3.5 s when the model writes first. Changing the instructions alone did not fix the order. The proposal (option E) moves naming to a small parallel call in the agent service, about $0.0005 per new session versus about $0.006 today. Mahmoud approved it on 2026-10-29 and added two decisions: (1) the rename tools and the naming instructions go away entirely, and old agents get the tools dropped at resolve time; (2) self-hosting users choose the model for this internal call through new environment variables (OpenAI-compatible URL, key, model), with docs. The runner already gives each new session a temporary title (the first message, cut to 60 chars) about 0.3 s into the turn.
